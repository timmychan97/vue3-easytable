:::demo 1. Egenskapen `name` setter ikonnavnet<br> 2. Egenskapen `size` setter ikonstørrelsen<br> 3. Egenskapen `color` setter ikonfarven

```html
<template>
    <div>
        <ve-icon name="double-right-arrow" />
        <ve-icon name="double-right-arrow" color="red" />
        <ve-icon name="double-right-arrow" :size="40" />
    </div>
</template>
```
