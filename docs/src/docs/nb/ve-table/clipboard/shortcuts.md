:::anchor Hurtigtaster

Utklippstavlefunksjonen stotter folgende hurtigtaster (basert pa Excel-hurtigtaster):

| Funksjon                                    | Hurtigtast   |
| :------------------------------------------ | :----------- |
| Kopier innholdet i valgte celler            | `Ctrl` + `C` |
| Lim inn (stotter Excel-innholdsformat)      | `Ctrl` + `V` |
| Klipp ut innholdet i valgte celler          | `Ctrl` + `X` |
| Slett innholdet i valgte celler             | `Delete`     |
