:::tip
1. Egenskapen `scroll-width` angir bredden pa rulleomradet<br>
2. Nar den ytre containerens bredde er mindre enn `scroll-width`-verdien, vises et horisontalt rullefelt; nar den ytre containerens bredde er storre enn `scroll-width`-verdien, tilpasses den til containeren; nar `scroll-width=0`, avhenger rullefeltet av kolonnebreddene dine<br>
3. Kolonnebredder kan vaere uangitt, angitt som prosent eller angitt som pikselverdier (px)<br>
4. Nar `scroll-width`-egenskapen er satt, er det **sterkt anbefalt a holde kolonnebreddeenhetene konsistente!**<br>

:::
