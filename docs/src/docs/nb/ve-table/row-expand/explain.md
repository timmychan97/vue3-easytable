::: tip
1. Konfigurer radutvidelse via egenskapen `expandOption`.<br>
2. Sett `type=expand` i `columns` for å definere utvid-kolonnen.
3. Sett egenskapen `rowKeyFieldName` til det tilsvarende kolonnenavnet i raddataene.<br>
4. `render`-funksjonen tillater tilpasset utvid-innhold, her med JSX-syntaks.<br>

:::
