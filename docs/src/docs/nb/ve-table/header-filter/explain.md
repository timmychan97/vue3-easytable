:::tip
1. Sett opp filtreringsfunksjonen gjennom `filter`-egenskapen paa `column`-objektet<br>
2. `filterList` angir filterbetingelsene dine. Den inneholder 3 egenskaper: `label`, `value`, `selected`<br>
3. `isMultiple` aktiverer flervalg for filterelementer, standard er false<br>
4. `filterConfirm` er bekreft-funksjonen for filteret<br>
5. `filterReset` er tilbakestill-funksjonen for filteret<br>
:::
