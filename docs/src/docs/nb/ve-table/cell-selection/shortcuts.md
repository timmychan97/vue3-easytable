::: anchor Tastatursnarveier

Cellevalg støtter følgende tastatursnarveier (basert på Excel-snarveier):

| Funksjon                          | Snarvei           |
| :-------------------------------- | :---------------- |
| Flytt aktiv celle opp             | `↑`               |
| Flytt aktiv celle til høyre       | `→`               |
| Flytt aktiv celle ned             | `↓`               |
| Flytt aktiv celle til venstre     | `←`               |
| Flytt aktiv celle ned             | `Enter`           |
| Flytt aktiv celle opp             | `Shift` + `Enter` |
| Flytt aktiv celle til høyre       | `Tab`             |
| Flytt aktiv celle til venstre     | `Shift` + `Tab`   |
