::: tip
1. Aktiver radiovalg-funksjonen via egenskapen `radioOption`.<br>
2. Sett `type=radio` i `columns` for å definere radiovalg-kolonnen.<br>
3. Sett egenskapen `rowKeyFieldName` til det tilsvarende kolonnenavnet i raddataene.<br>
4. `selectedRowChange` er hendelsen for radendring. Den mottar 1 parameter: `row` – gjeldende raddata.
:::
