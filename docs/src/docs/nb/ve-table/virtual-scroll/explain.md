:::tip
1. Egenskapen `virtualScrollOption` aktiverer virtuell rulling. Det anbefales ved visning av **1000 eller flere** rader samtidig, og kan håndtere **over 200 000** rader<br>
2. Egenskapen `maxHeight` setter maksimalhøyden for det virtuelle rulleområdet. `maxHeight` er en obligatorisk egenskap<br>
3. `rowKeyFieldName` er en obligatorisk egenskap. `rowKeyFieldName`-egenskapen tilsvarer kolonnenavnet i raddataene<br>
4. **Etter aktivering av virtuell rulling er alle andre funksjoner fortsatt tilgjengelige**

:::
