::: tip
1. Kolonnegruppering i toppteksten oppnås ved å sette egenskapen `children` på `columns`<br>
2. Egenskapen `children` angir kolonnene som skal slås sammen<br>
3. Egenskapen `key` må spesifiseres for hver kolonne når kolonnegruppering brukes!<br>
4. Når du trenger å feste grupperte kolonner, er det tilstrekkelig å sette egenskapen `fixed` på toppnivåkonfigurasjonen

:::
