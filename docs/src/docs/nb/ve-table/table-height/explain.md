:::tip
1. Tabellhøyden bestemmes som standard av raddata. Du kan også sette maksimalhøyden med `max-height`-egenskapen<br>
2. Tabellhøyden kan settes til en fast verdi, f.eks.: `:max-height="500"`<br>
3. Tabellhøyden kan settes til en dynamisk verdi, f.eks.: `max-height="calc(100vh - 210px)"` eller `max-height="80%"`<br>

:::
