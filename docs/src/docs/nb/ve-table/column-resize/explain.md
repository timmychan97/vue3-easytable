:::tip
1. Kolonnestorrelsesendring er veldig nyttig nar du arbeider med store tekstinnhold<br>
2. Konfigurer kolonnedragningsfunksjonen via `columnWidthResizeOption`<br>
3. Det anbefales a sette `scroll-width=0`, slik at nar den totale kolonnebredden overstiger containerbredden, vises et horisontalt rullefelt<br>
4. Sett standard kolonnebredde via `column.width`. Hvis den totale bredden pa alle kolonner er mindre enn containerbredden, tilpasses kolonnebreddene automatisk
:::
