:::anchor Hurtigtaster

Redigerbare celler stotter folgende hurtigtaster (basert pa Excel-hurtigtaster):

| Funksjon                                                          | Hurtigtast        |
| :---------------------------------------------------------------- | :---------------- |
| Ga inn i redigeringsmodus for den aktive cellen                   | `F2`              |
| Stopp redigering og bli pa gjeldende celle                        | `Ctrl` + `Enter`  |
| Linjeskift i celletekst                                           | `Alt` + `Enter`   |
| Tom innholdet i den aktive cellen                                 | `Delete`          |
| Tom innholdet i den aktive cellen og ga inn i redigeringsmodus    | `BackSpace`       |
| Tom innholdet i den aktive cellen og fyll inn et mellomrom        | `Space`           |
| Stopp redigering og flytt den aktive cellen ned                   | `Enter`           |
| Stopp redigering og flytt den aktive cellen opp                   | `Shift` + `Enter` |
| Stopp redigering og flytt den aktive cellen til hoyre             | `Tab`             |
| Stopp redigering og flytt den aktive cellen til venstre           | `Shift` + `Tab`   |
| Skriv direkte i en redigerbar celle for a ga inn i redigeringsmodus | -                 |
| Automatisk tilpasning av redigeringsboksen ved lang tekst         | -                 |
