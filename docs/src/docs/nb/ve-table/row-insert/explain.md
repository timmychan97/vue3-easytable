::: tip
1. Når musepekeren holdes over indekskolonnen (operasjonskolonnen), vises en visuell indikator som viser hvor en ny rad kan settes inn.<br>
2. Plusstegn-knappen og den horisontale linjen angir innsettingspunktet mellom rader.<br>
3. Fungerer sømløst med virtuell rulling – korrekt radindeks oppdages alltid.<br>
4. En indeks-/operasjonskolonne (`operationColumn: true`) må defineres i columns.<br>
5. Egenskapen `rowKeyFieldName` bør angis for korrekt identifikasjon av rader.

:::
