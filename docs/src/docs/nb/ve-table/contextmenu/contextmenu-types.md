:::anchor Kontekstmenyliste

Kontekstmenyliste for overskrift

| Funksjon                              | Type                           |
| :------------------------------------ | :----------------------------- |
| Skillelinje                           | `SEPARATOR`                    |
| Klipp ut                              | `CUT`                          |
| Kopier                                | `COPY`                         |
| Tom kolonne                           | `EMPTY_COLUMN`                 |
| Frys venstre kolonne til denne kolonnen | `LEFT_FIXED_COLUMN_TO`         |
| Frys hoyre kolonne til denne kolonnen | `RIGHT_FIXED_COLUMN_TO`        |
| Avbryt frysing av venstre kolonne     | `CANCEL_LEFT_FIXED_COLUMN_TO`  |
| Avbryt frysing av hoyre kolonne       | `CANCEL_RIGHT_FIXED_COLUMN_TO` |

Kontekstmenyliste for tabellinnhold

| Funksjon            | Type               |
| :------------------ | :----------------- |
| Skillelinje         | `SEPARATOR`        |
| Klipp ut            | `CUT`              |
| Kopier              | `COPY`             |
| Sett inn rad over   | `INSERT_ROW_ABOVE` |
| Sett inn rad under  | `INSERT_ROW_BELOW` |
| Fjern rad           | `REMOVE_ROW`       |
| Tom rad             | `EMPTY_ROW`        |
| Tom celle           | `EMPTY_CELL`       |
