## @vue3-easytable/vue

En tabellkomponent basert pa Vue 3.x.

### Funksjoner

-   Bruker virtuell rullingsteknologi, stotter visning av **300 000 rader** med data
-   **Gratis for alltid**. Du kan selvfolgelig ogsa velge a donere

### Funksjonalitet

**Grunnkomponenter**

-   Loading-komponent
-   Pagineringskomponent
-   Kontekstmeny (hoyreklikksmeny)-komponent
-   Ikonkomponent
-   Locale (internasjonalisering)-komponent

**Tabellkomponent**

-   Internasjonalisering
-   Tematilpasning
-   Innebygde temaer
-   Faste kolonner
-   Fast topptekst
-   Topptekstgruppering
-   Filter
-   Sortering
-   Kolonnebredde-dra
-   Cellestiler
-   Cellesammenslaning
-   Celletilpasning
-   Cellevalg (tastaturoperasjon)
-   Automatisk celleutfylling
-   Celleredigering
-   Utklippstavle
-   Kontekstmeny
-   Celleellipse
-   Enkeltvalg av rad
-   Flervalg av rad
-   Radutvidelse
-   Radstiler
-   Bunntekst
-   Paginering
-   Virtuell rulling
-   Egendefinerte hendelser
