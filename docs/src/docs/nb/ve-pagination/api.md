### props

| Parameter      | Beskrivelse                                                                                                                                                                                                                                                                                               | Type                    | Alternativer                                          | Standard                                              |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------- | ----------------------------------------------------- | ----------------------------------------------------- |
| layout         | Layoutinnstillinger                                                                                                                                                                                                                                                                                       | `Array`                 | ['total', 'prev', 'pager', 'next', 'sizer', 'jumper'] | ['total', 'prev', 'pager', 'next', 'sizer', 'jumper'] |
| total          | Totalt antall                                                                                                                                                                                                                                                                                             | `Number`                | -                                                     | -                                                     |
| pageIndex      | Gjeldende sidenummer                                                                                                                                                                                                                                                                                      | `Number`                | -                                                     | 1                                                     |
| pagingCount    | Antall knapper mellom de første 5 sidene og de siste 5 sidene                                                                                                                                                                                                                                             | `Number`                | -                                                     | 5                                                     |
| pageSize       | Sidestørrelse                                                                                                                                                                                                                                                                                             | `Number`                | -                                                     | 10                                                    |
| pageSizeOption | Nedtrekksalternativer for sidestørrelse                                                                                                                                                                                                                                                                   | `Array`                 | -                                                     | [10, 20, 30]                                          |
| popperAppendTo | Overordnet node for nedtrekkspopup-laget. Standard er å rendres på `body`. Hvis du opplever posisjoneringsproblemer ved rulling i menyer, prøv å endre dette til det rullbare området og posisjonere relativt til det. [Eksempel](https://codesandbox.io/s/vue-easytable-2-15-0-example-forked-q9k3m0?file=/Example.vue) | `String \| HTMLElement` | -                                                     | document.body                                         |

### Event

| Hendelsesnavn         | Beskrivelse                            | Tilbakekallingsparametere |
| --------------------- | -------------------------------------- | ------------------------- |
| on-page-number-change | Tilbakekall ved endring av sidenummer  | Gjeldende sidenummer      |
| on-page-size-change   | Tilbakekall ved endring av sidestørrelse | Sidestørrelse            |
