:::tip
1. When the mouse hovers over the index column (operation column), a visual indicator is displayed showing where a new row can be inserted.<br>
2. The plus button and horizontal line indicate the insertion point between rows.<br>
3. Works seamlessly with virtual scrolling - the correct row index is always detected.<br>
4. An index/operation column (`operationColumn: true`) must be defined in columns.<br>
5. The `rowKeyFieldName` property should be specified to correctly identify rows.

:::
