:::tip
1. Set the filter feature through the `filter` property of the `column` object<br>
2. `filterList` sets your filter conditions. It contains 3 properties: `label`, `value`, `selected`<br>
3. `isMultiple` enables multi-select for filter items, defaults to false<br>
4. `filterConfirm` is the filter confirm function<br>
5. `filterReset` is the filter reset function<br>
:::
