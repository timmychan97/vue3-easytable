:::tip
1. The table height is determined by row data by default. You can also set the maximum height using the `max-height` property<br>
2. The table height can be set to a fixed value, e.g.: `:max-height="500"`<br>
3. The table height can be set to a dynamic value, e.g.: `max-height="calc(100vh - 210px)"` or `max-height="80%"`<br>

:::
