Header context menu list

| Function                          | Type                           |
| :-------------------------------- | :----------------------------- |
| Separator                         | `SEPARATOR`                    |
| Cut                               | `CUT`                          |
| Copy                              | `COPY`                         |
| Empty column                      | `EMPTY_COLUMN`                 |

| Freeze right column to this column| `RIGHT_FIXED_COLUMN_TO`        |

| Cancel right column freeze        | `CANCEL_RIGHT_FIXED_COLUMN_TO` |
