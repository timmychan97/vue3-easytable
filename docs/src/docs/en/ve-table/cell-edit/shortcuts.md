:::anchor Shortcuts

Editable cells support the following shortcuts (based on Excel shortcuts):

| Function                                                          | Shortcut          |
| :---------------------------------------------------------------- | :---------------- |
| Enter edit mode for the active cell                               | `F2`              |
| Stop editing and stay on the current cell                         | `Ctrl` + `Enter`  |
| Line break within cell text                                       | `Alt` + `Enter`   |
| Clear active cell content                                         | `Delete`          |
| Clear active cell content and enter edit mode                     | `BackSpace`       |
| Clear active cell content and fill with a space                   | `Space`           |
| Stop editing and move active cell down                            | `Enter`           |
| Stop editing and move active cell up                              | `Shift` + `Enter` |
| Stop editing and move active cell right                           | `Tab`             |
| Stop editing and move active cell left                            | `Shift` + `Tab`   |
| Type directly in an editable cell to enter edit mode              | -                 |
| Auto-resize the edit box when entering long text                  | -                 |
