:::tip
1. Set `operationColumn=true` in columns to designate an operation column <br>
2. The operation column is fixed to the left by default <br>
3. The operation column supports row multi-select, entire row copy, entire row cut, row position swap (in development), and other row operations. This column functions similarly to the operation column in Excel<br>
4. Cells in the operation column do not allow cell selection, cell editing, or cell autofill

:::
