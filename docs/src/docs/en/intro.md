## @vue3-easytable/vue

A table component based on Vue 3.x.

### Features

-   Uses virtual scrolling technology, supporting display of **300,000 rows** of data
-   **Free forever**. Of course, you can also choose to donate

### Functionality

**Base Components**

-   Loading component
-   Pagination component
-   Contextmenu (right-click menu) component
-   Icon component
-   Locale (internationalization) component

**Table Component**

-   Internationalization
-   Theme customization
-   Built-in themes
-   Fixed columns
-   Fixed header
-   Header grouping
-   Filter
-   Sort
-   Column width dragging
-   Cell styles
-   Cell merging
-   Cell customization
-   Cell selection (keyboard operation)
-   Cell autofill
-   Cell editing
-   Clipboard
-   Context menu
-   Cell ellipsis
-   Row single selection
-   Row multiple selection
-   Row expand
-   Row styles
-   Footer
-   Pagination
-   Virtual scrolling
-   Custom events

### Supported Environments

-   Modern browsers and IE11+
