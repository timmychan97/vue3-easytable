:::anchor Usage

:::demo 1. The `name` property sets the icon name<br> 2. The `size` property sets the icon size<br> 3. The `color` property sets the icon color

```html
<template>
    <div>
        <ve-icon name="double-right-arrow" />
        <ve-icon name="double-right-arrow" color="red" />
        <ve-icon name="double-right-arrow" :size="40" />
    </div>
</template>
```

:::
