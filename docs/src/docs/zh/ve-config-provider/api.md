### props

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
| ---- | ---- | ---- | ------ | ------ |
| locale | 提供者内组件使用的语言。合并在外层语言（最近的外层 `VeConfigProvider`，没有时为当前 app 的语言，再没有时为全局语言）之上，可以只包含需要修改的键。键名见[国际化](./locale)。已废弃的英文键仍可使用，每个键只会给出一次弃用警告。 | `Object` | - | - |

### slots

| 名称 | 说明 |
| ---- | ---- |
| default | 使用该语言的组件 |
