:::tip
1、通过 `sortBy`属性，设置需要排序的列。`sortBy="asc"`：默认当前列升序；`sortBy="desc"`：默认当前列降序；`sortBy=""`：允许排序但无排序规则<br>
2、通过 `sortOption`对象，设置更多排序功能。排序功能需要配合`sortChange(param)`回调函数实现，回调参数包含列的排序规则<br>
3、回调参数以 `field` 为键，例如 `{ age: 'asc', weight: '' }`。每一列（按 `key`）单独保存排序状态，多列可以使用同一个 `field`：此时参数中是其中第一个有排序规则的列。没有 `field` 的可排序列也能排序，但不出现在回调参数中
:::
